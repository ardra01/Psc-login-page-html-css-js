# Psc-login-page-html-css-js
A Kerala Public Service Commission (PSC) inspired login page created using HTML, CSS, and JavaScript.
This project recreates a PSC-style user interface with a navigation section, registration/login panel, CAPTCHA generation and validation, password field, help desk information, and general user links.

Technologies Used

* HTML5

* CSS3

* JavaScript

Features

* PSC-inspired webpage design

* User ID and password fields

* Random CAPTCHA generation

* CAPTCHA refresh functionality

* Basic login validation

* Registration and password-management links

* Responsive viewport setup

* Help desk and general information section
